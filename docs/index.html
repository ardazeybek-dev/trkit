trkit

Türkçe metin araçları ve Türkiye'ye özgü doğrulayıcılar. Python paketi — hem kütüphane, hem komut satırı aracı.

$ pip install trkit
PyPI · v0.1.0 GitHub MIT lisansı Python 3.9+

Çözdüğü problem

Python'un yerleşik upper() ve lower() metotları İngilizce kurallarına göre çalışır. Türkçedeki noktalı/noktasız i ayrımını bilmezler — bu yüzden şehir adlarını, isimleri, arama sorgularını sessizce bozarlar.

✗ Python'un kendisi

"istanbul".upper()→ISTANBUL
"IĞDIR".lower()→iğdır
"izmir".title()→Izmir

✓ trkit ile

upper("istanbul")→İSTANBUL
lower("IĞDIR")→ığdır
title("izmir")→İzmir

IBAN doğrulama

Türkiye IBAN'ı, ISO 13616 mod-97 kontrolü. Boşluklar önemsiz.

IBAN bekleniyor

Plaka ↔ il

Kod yaz il gelsin (35), il yaz kod gelsin (İzmir). 81 il kayıtlı.

Nasıl kullanılır

İki yolu var: kendi Python kodunun içinden, ya da doğrudan terminalden.

# önce kur:  pip install trkit
from trkit import upper, lower, title, slugify, asciify
from trkit import is_valid_tckn, is_valid_iban
from trkit import city_from_plate, plate_from_city

upper("istanbul")                 # 'İSTANBUL'
lower("IĞDIR")                    # 'ığdır'
title("izmir kuş cenneti")        # 'İzmir Kuş Cenneti'
asciify("Çiğdem Şahin")            # 'Cigdem Sahin'
slugify("Çığır Açan Şeyler")      # 'cigir-acan-seyler'

is_valid_tckn("10000000146")       # True
is_valid_iban("TR33 0006 1005 1978 6457 8413 26")  # True

city_from_plate(35)               # 'İzmir'
plate_from_city("İSTANBUL")         # 34
$ trkit slug "Çığır Açan Şeyler"
cigir-acan-seyler

$ trkit upper istanbul
İSTANBUL

$ trkit plaka 35
İzmir

$ trkit plaka İzmir
35

$ trkit tckn 10000000146
geçerli

# doğrulama komutları çıkış kodu döndürür (geçerli → 0, geçersiz → 1),
# yani kabuk betiklerinde doğrudan kullanılabilir:
if trkit iban "$IBAN" > /dev/null; then
    echo "IBAN kabul edildi"
fi
